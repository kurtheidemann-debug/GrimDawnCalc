## Scope and reruns

Candidates retaining at least 95% of the reference offense and defense index prefer lower cost, with health/DA/absorption within 5% and armor within 10% of the reference. Stronger cheaper alternatives also qualify. The three objectives can legitimately select the same loadout. All selected builds satisfy caps and listed defensive floors, resource eligibility, fixed-save invariants and equip-order checks. Search uses a finite bundle shortlist and beam; no global optimum claim. Current level and available items come from the snapshot; refresh the save before advising later levels. Existing decoder limitations remain. Item IDs are snapshot-specific.

Run `python practical_optimizer.py` for an input-hashed cached rerun. Run `python practical_optimizer.py --force` to recompute. Run `python -m unittest discover -v` for preserved and new tests. Refresh with the existing `refresh_data.py` before new levels; use `--data` to point at refreshed extracted data. No source save is written.

Detailed component/augment record paths, stats, resources and states are in practical-results/results.json. Previous results and original optimizer remain under archive/.
